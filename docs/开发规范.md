# 悬浮待办事项软件 — 开发规范

> 版本：v1.0 | 最后更新：2026-06-29

## 1. 编码规范

- **语言**：所有代码注释、变量命名、用户界面使用简体中文
- **代码注释**：复杂逻辑必须注释说明意图
- **类型注解**：所有函数参数和返回值使用 Python 类型注解
- **导入规范**：标准库 → 第三方库 → 本地模块，分组排列

## 2. 代码风格

- 遵循 PEP 8
- 行宽 100 字符
- 使用 4 空格缩进
- 类名：`PascalCase`
- 函数/变量：`snake_case`
- 常量：`UPPER_SNAKE_CASE`
- 信号：`snake_case`，以 `signal_` 前缀（如 `signal_item_completed`）

## 3. Git 规范（如使用）

- 分支：`main`（稳定） / `dev`（开发）
- 提交信息格式：`[类型] 简短描述`
  - `[feat]` 新功能
  - `[fix]` 修复
  - `[docs]` 文档
  - `[refactor]` 重构
  - `[style]` 样式

## 4. 测试要求

- 数据模型层：逻辑覆盖（序列化/反序列化、CRUD）
- 控制器层：边界条件（空列表、损坏文件、权限错误）
- 视图层：手动 UI 测试（所有交互相应可用）

## 5. 提交检查

推送前确认：
- [ ] 无未处理的异常
- [ ] JSON 文件读写正常
- [ ] 窗口置顶生效
- [ ] 折叠/展开切换正常
- [ ] 新增待办可保存
- [ ] 办结后自动归档

## 6. 开发日志规范

每次开发结束后，在 `dev-log/` 下以 `YYYY-MM-DD.md` 格式记录：
1. 今日完成事项
2. 遇到的问题及解决
3. 明日待办计划
4. 备注/提醒
