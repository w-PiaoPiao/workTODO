# 悬浮待办事项软件 — 需求文档

> 版本：v2.0 | 最后更新：2026-07-31

## 1. 项目概述

一个 Windows 桌面的待办事项和便签软件，像便利贴一样悬浮在桌面，帮助用户快速记录和管理待办事项。

## 2. 用户需求

| 需求 | 描述 | 优先级 | 状态 |
|------|------|--------|------|
| 桌面悬浮 | 窗口始终在桌面最上层，不被其他窗口遮挡 | P0 | ✅ |
| 可大可小 | 折叠为紧凑条（仅显示计数），展开为完整列表 | P0 | ✅ |
| 快速添加 | 在折叠和展开模式下都能一键添加新待办 | P0 | ✅ |
| 进度记录 | 每个待办可以多次添加进度描述，带时间戳 | P0 | ✅ |
| 快速办结 | 一键勾选完成，自动记录完成时间 | P0 | ✅ |
| 自动归档 | 已办结内容自动移入归档，可随时查看恢复 | P0 | ✅ |
| 搜索筛选 | 按关键词搜索过滤待办列表 | P1 | ✅ |
| 系统托盘 | 最小化到系统托盘，后台运行 | P1 | ✅ |
| 键盘快捷键 | Ctrl+N 新建，Esc 折叠等 | P1 | ✅ |
| 开机自启 | 可选的开机自动启动 | P2 | ✅ |
| 深色/浅色主题 | 一键切换，持久化记忆 | P1 | ✅ |
| 截止日期 | 设置截止日期，过期红色高亮，到期托盘提醒 | P1 | ✅ (v0.4.0) |
| 分类标签 | 标题 #标签 自动提取，顶部筛选 | P2 | ✅ (v0.4.0) |
| 便签功能 | 彩色便利贴，独立于待办的纯文本笔记 | P1 | ✅ (v0.4.0) |
| 数据备份 | 导出全部数据为 JSON，可导入恢复 | P1 | ✅ (v0.4.0) |
| 统计视图 | 今日/本周/累计完成数 | P2 | ✅ (v0.4.0) |
| 跟随系统主题 | 自动跟随 Windows 深浅色模式 | P2 | ✅ (v0.4.0) |
| 字号缩放 | 界面字号可调（85%~130%） | P3 | ✅ (v0.4.0) |
| 桌宠形态 | 折叠后变为桌面宠物：自定义图片形象（白底自动去除）、空闲动画、计数角标、右键菜单 | P2 | ✅ (v0.4.1) |

## 3. 功能边界

- **数据存储**：本地 JSON 文件，不涉及网络同步
- **用户数**：单机单用户
- **平台**：Windows 11（兼容 Windows 10）
- **语言**：简体中文
