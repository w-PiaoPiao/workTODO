# 悬浮待办事项软件 — 设计规范

> 版本：v1.0 | 最后更新：2026-06-29

## 1. 视觉风格

Windows 11 Fluent Design 风格，简洁圆润，低饱和度色彩。

## 2. 色彩方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景主色 | `#F3F3F3` | 浅灰，Windows 11 风格 |
| 卡片白色 | `#FFFFFF` | 待办卡片背景 |
| 悬停高亮 | `#E5F3FF` | 鼠标悬停底色 |
| 主文字 | `#1A1A1A` | 标题/正文 |
| 次要文字 | `#666666` | 时间戳、辅助信息 |
| 强调色 | `#0078D4` | 按钮、选中、链接 (Win11 蓝) |
| 成功色 | `#107C10` | 已完成状态 |
| 危险色 | `#D13438` | 删除操作 |
| 分割线 | `#E0E0E0` | 边框/分割 |

## 4. 窗口尺寸

| 模式 | 尺寸 | 说明 |
|------|------|------|
| 折叠（桌宠） | 140 × 140 px | 透明背景，形象绘制基准 116 px（四周 12px 边距容纳动画超程） |
| 展开 | 400 × 520 px | 完整列表 |
| 最小展开 | 320 × 300 px | 内容很少时 |
| 最大展开 | 500 × 700 px | 可拖拽调整 |

## 4.1 桌宠规范

- **素材**：PNG / JPG / GIF，正方形、≥512×512、主体居中；白底 JPG/PNG 自动去除连通边缘白色背景（内部白色保留），结果缓存复用
- **计数角标**：右上角 accent 色圆角气泡（白描边保证双主题醒目），0 隐藏，99+ 封顶
- **空闲动画**（程序驱动，静态图同样生效）：
  - 漂浮：上下 ±5px 往返（6.4s 周期）
  - 呼吸：缩放 1.0 ↔ 1.05（3.6s 周期）
  - 随机小动作：每 6~14s 随机歪头（±8°）或跳跃（12px）
  - 悬停反馈：鼠标进入弹跳放大一次（1.0→1.12→1.0）
- **交互**：单击展开、拖拽移动、右键菜单（展开/快速添加/置顶/退出）

## 5. 布局规范

- **圆角**：4px（折叠）、8px（展开窗口）
- **内边距**：12px（展开模式）
- **阴影**：展开模式带 drop shadow
- **动画**：折叠/展开过渡 200ms ease-out
- **边距**：窗口默认贴右上角，距屏幕边缘 20px

## 6. 交互规范

| 操作 | 行为 |
|------|------|
| 拖拽 | 按住窗口空白区域拖动 |
| 双击标题栏 | 切换折叠/展开 |
| 办结 | 单选框切换，卡片淡出动画 |
| 删除 | 弹出确认对话框 |
| 搜索 | 实时过滤，300ms 防抖 |
| 快速添加 | 回车提交，自动清空输入框 |
