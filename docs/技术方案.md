## 3. 数据模型

### ProgressEntry（进度条目）

```python
@dataclass
class ProgressEntry:
    text: str          # 进度描述
    timestamp: str     # ISO-8601 时间戳 "2026-06-29T14:30:00+08:00"
```

### TodoItem（待办项）

```python
@dataclass
class TodoItem:
    id: str                       # uuid4 hex
    title: str                    # 标题
    status: str                   # "active" | "completed" | "archived"
    created_at: str               # 创建时间
    completed_at: str | None      # 完成时间
    progress: list[ProgressEntry] # 进度记录
    sticky: bool                  # 是否置顶
    position: int                 # 手动排序位置（0=最前）
    due_date: str | None          # 截止日期 "YYYY-MM-DD"
    tags: list[str]               # 分类标签（标题中 #标签 自动提取）
```

### Note（便签）

```python
@dataclass
class Note:
    id: str                       # uuid4 hex
    content: str                  # 便签内容（多行）
    created_at: str               # 创建时间
    updated_at: str               # 更新时间
    color: str                    # 颜色 key（yellow/blue/green/pink/white）
```

### JSON 存储格式

**todos.json** — 活跃待办
```json
[
  {
    "id": "a1b2c3d4",
    "title": "完成项目方案 #工作",
    "status": "active",
    "created_at": "2026-06-29T09:00:00+08:00",
    "completed_at": null,
    "progress": [
      {"text": "已和团队对齐需求", "timestamp": "2026-06-29T14:30:00+08:00"}
    ],
    "sticky": false,
    "position": 0,
    "due_date": "2026-08-05",
    "tags": ["工作"]
  }
]
```

**archive.json** — 已归档（格式相同，status 为 "archived"）

**notes.json** — 便签
```json
[
  {
    "id": "n1",
    "content": "记得带伞",
    "created_at": "2026-07-31T09:00:00+08:00",
    "updated_at": "2026-07-31T09:00:00+08:00",
    "color": "yellow"
  }
]
```

**备份文件** — 导出/导入数据
```json
{
  "app": "待办事项和便签",
  "version": "0.4.0",
  "exported_at": "2026-07-31T09:00:00+08:00",
  "todos": [...],
  "archived": [...]
}
```

### 数据流示例：办结操作

```
用户点击 ☑ → TodoCard 信号 emit → AppController.on_complete()
  → 更新 status + 时间戳 → store.archive_item()
    → 从 todos.json 移除 → 追加到 archive.json
  → 刷新视图 → 更新计数 → 桌面通知 "已办结"
```

## 5. 原子写入策略

防止 JSON 文件损坏：

```python
def _save_json(path, data):
    tmp = path.with_suffix(".tmp")
    tmp.write_text(json.dumps(data, ensure_ascii=False, indent=2))
    tmp.replace(path)  # Windows NTFS 原子重命名
```

## 6. 性能策略：内存缓存 + 防抖落盘

高频操作（添加进度、编辑）只修改内存并标记脏，由控制器 500ms 防抖定时器统一落盘：

```
用户操作 → TodoStore 修改缓存（标脏） → 控制器 QTimer(500ms) → flush() 原子写盘
                                                                  ↑ 退出时 aboutToQuit 强制 flush
```

- `load_todos()` / `load_archived()` 首次读盘后驻留内存
- 写操作（add/update/delete/archive/restore/reorder/auto_archive）不立即写盘
- `flush()` 只写有脏标记的文件；`save_todos`/`save_archived` 保留立即写盘语义
- 便签（NoteStore）数量小，保持立即写盘

## 7. 错误处理

| 场景 | 处理 |
|------|------|
| JSON 损坏 | 重命名 .bak，返回空列表，提示用户 |
| 权限错误 | 弹窗报错，不丢数据 |
| 首次启动 | 自动创建 data/ 目录 |

## 8. 系统集成

| 功能 | 实现方式 |
|------|----------|
| 开机自启 | HKCU\...\Run 注册表（打包模式 VBS 包装避免弹窗） |
| 深色跟随系统 | 轮询 HKCU\...\Themes\Personalize\AppsUseLightTheme（30 秒） |
| 截止日期提醒 | 启动 + 每小时检查，QSettings 记录当天已提醒 id 去重 |
| 单实例 | QLockFile（崩溃后自动释放） |
