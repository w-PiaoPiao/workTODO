## 3. 数据模型

### ProgressEntry（进度条目）

```python
@dataclass
class ProgressEntry:
    text: str          # 进度描述
    timestamp: str     # ISO-8601 时间戳 "2026-06-29T14:30:00+08:00"
```

### TodoItem（待办项）

```python
@dataclass
class TodoItem:
    id: str                       # uuid4 hex
    title: str                    # 标题
    status: str                   # "active" | "completed" | "archived"
    created_at: str               # 创建时间
    completed_at: str | None      # 完成时间
    progress: list[ProgressEntry] # 进度记录
```

### JSON 存储格式

**todos.json** — 活跃待办
```json
[
  {
    "id": "a1b2c3d4",
    "title": "完成项目方案",
    "status": "active",
    "created_at": "2026-06-29T09:00:00+08:00",
    "completed_at": null,
    "progress": [
      {"text": "已和团队对齐需求", "timestamp": "2026-06-29T14:30:00+08:00"}
    ]
  }
]
```

**archive.json** — 已归档（格式相同，status 为 "archived"）

### 数据流示例：办结操作

```
用户点击 ☑ → TodoCard 信号 emit → AppController.on_complete()
  → 更新 status + 时间戳 → store.archive_item()
    → 从 todos.json 移除 → 追加到 archive.json
  → 刷新视图 → 更新计数 → 桌面通知 "已办结"
```

## 5. 原子写入策略

防止 JSON 文件损坏：

```python
def _save_json(path, data):
    tmp = path.with_suffix(".tmp")
    tmp.write_text(json.dumps(data, ensure_ascii=False, indent=2))
    tmp.replace(path)  # Windows NTFS 原子重命名
```

## 6. 错误处理

| 场景 | 处理 |
|------|------|
| JSON 损坏 | 重命名 .bak，返回空列表，提示用户 |
| 权限错误 | 弹窗报错，不丢数据 |
| 首次启动 | 自动创建 data/ 目录 |
