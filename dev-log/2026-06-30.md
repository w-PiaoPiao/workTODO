### Bug 修复：QMessageBox 确认删除弹窗黑底（本轮）

**现象**：点击删除后 QMessageBox 确认框纯黑背景，仅显示一个蓝色圆形图标。

**根因**：全局 QSS 的 `QWidget { color: #1A1A1A; }` 规则使所有 widget
改用 QSS 渲染模式，但未设置 background；QMessageBox 本身无 QSS 规则，
background 走默认（黑底）。

**修复**：在 `theme.py` 的 `global_qss()` 中新增 `QMessageBox` 样式
- 背景白底 `#FFFFFF`
- 标签文字 `#1A1A1A`
- 按钮边框+圆角+悬停效果

**修改**：`app/views/theme.py` — global_qss() 尾部加 QMessageBox 规则块

### Bug 修复：CMD 窗口弹窗报错 '不是内部或外部命令'（本轮）

**现象**：启动软件时同时弹出一个 CMD 窗口，显示乱码命令名。

**根因**：`run.bat` / `run_hidden.bat` 以 **UTF-8 无 BOM + LF 换行**
保存。Windows cmd.exe 按 **GBK(936)** 解析文件，UTF-8 中文注释的
字节码被误解析为命令名 → cmd 报错找不到该"命令"。

**修复**：注释改英文（纯 ASCII → 任何代码页解析一致）+ CRLF 行尾
