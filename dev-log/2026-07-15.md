# 开发日志 2026-07-15

## 完成功能：贴顶隐藏

实现了窗口拖拽到屏幕顶部后自动收起隐藏的功能，类似系统任务栏的自动隐藏效果。

### 实现细节

- **触发条件**：拖拽窗口使顶部边缘距屏幕顶部 ≤ 10px 时，松开鼠标自动贴顶隐藏
- **隐藏效果**：窗口上移只露出底部 6px 像素条，作为唤出"把手"
- **展开/隐藏循环**（优化后）：
  - 鼠标悬停在顶部热区 → 窗口临时展开（_temporarily_visible）
  - 鼠标离开窗口区域 → 500ms 后自动再次隐藏
  - 鼠标移回窗口 → 取消隐藏计时，保持展开
  - 只有拖拽窗口（移动位置）才彻底取消贴顶模式
- **标题栏裁剪修复**：恢复位置 y = max(原位置, 屏幕顶部 + 2px)，确保标题栏完整可见
- **多屏支持**：记录贴顶时的屏幕信息，热区检测限定在当前屏幕
- **状态机**：三状态 — normal（普通）、hidden（贴顶隐藏）、peeking（临时展开），通过 `_stuck_to_top` + `_temporarily_visible` 控制

### 修改文件

- `app/config.py` — 添加 3 个贴顶隐藏配置常量
- `app/views/main_window.py` — 状态机重写：`_full_unstick`、`_temporarily_show`、`_schedule_hide`/`_do_hide`，`enterEvent`/`leaveEvent` 配合定时器
- `app/controllers/app_controller.py` — `_on_tray_show` 增加 `ensure_visible()` 调用
