# 开发日志 — 2026-07-03

## 今日完成

### 深色模式 (v0.2.0 新功能)

实现了完整的深色模式支持，用户可在运行时自由切换，偏好持久化。

**修改文件（共 7 个）：**

1. **`app/config.py`** — 新增 `DARK_COLORS` 深色配色方案（Windows 11 深色风格：背景 `#1E1E1E`、强调色 `#60CDFF`、文字 `#E0E0E0`）
2. **`app/views/theme.py`** — `AppTheme` 支持动态主题切换，新增 `switch_theme(dark)`、`is_dark()`、`apply_palette(app)`
3. **`app/views/collapsed_view.py`** — 添加 `reapply_theme()` 方法，追踪 `_pinned` 状态，提取样式应用到独立方法
4. **`app/views/expanded_view.py`** — 保存结构部件引用（`_title_bar`、`_footer`、`_collapse_btn`、`_quit_btn`），添加 `reapply_theme()`
5. **`app/views/custom_tooltip.py`** — 将硬编码的 `#FFFFFF`/`#1A1A1A` 改为从 `AppTheme.C` 动态读取
6. **`main.py`** — QPalette 设置改为使用 `AppTheme.apply_palette(app)` 动态获取
7. **`app/controllers/app_controller.py`** — 新增主题切换调度逻辑、系统托盘菜单项"🌙 深色模式"、QSettings 持久化

**不变的文件（自动适配主题）：**
- `todo_card.py` — 由 `refresh()` 重建时自动使用当前主题
- `archive_dialog.py` — 每次按需创建，始终使用当前主题
- `progress_widget.py` — 由 parent 重建时自动适配

**切换机制：**
- 展开视图标题栏 🔍 左边新增 🌙/☀️ 按钮，点击切换
- 首次启动从 QSettings 读取上次偏好
- 切换时：更新全局 QSS → 更新 QPalette → 更新自定义 tooltip → 重建各视图 → 持久化
