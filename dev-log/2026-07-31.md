# 开发日志 2026-07-31

## 版本：v0.3.1 → v0.4.0

功能增强 + 性能优化版本。

## 已完成

### 性能优化
- **TodoStore 内存缓存**：写操作只标记脏，控制器 500ms 防抖定时器统一落盘，退出时 `aboutToQuit` 强制 flush。消除高频操作（添加进度等）全量读写 JSON 文件。
- **透明度持久化防抖**：滑块拖动只实时更新窗口，松手（sliderReleased）才写入注册表。

### 新功能
- **截止日期 + 到期提醒**：TodoItem 新增 `due_date` 字段；卡片 📅 按钮设置/清除；今天/明天/已过期徽标（过期红色）；启动 + 每小时检查托盘提醒，QSettings 记录当天已提醒 id 去重。
- **分类标签**：TodoItem 新增 `tags` 字段；添加/编辑标题时自动提取 `#标签`；卡片显示标签 chips；列表顶部标签筛选行（全部 / #标签），与搜索叠加过滤。
- **彩色便签**：新增 Note 模型 + NoteStore（notes.json）；展开视图待办/便签 Tab 切换；NoteView 彩色便利贴列表 + NoteDialog 编辑（多行文本 + 5 色选择）；Ctrl+N 在便签页新建便签。
- **数据备份**：`TodoStore.export_all` / `import_all`（单个 JSON 含版本与时间戳，导入带格式校验与确认）；页脚 💾 备份按钮弹出导出/导入菜单。
- **统计面板**：标题栏 📊 按钮弹出面板，显示待办数、今日/本周/累计完成、归档数（扩展 `get_stats`）。
- **主题三态**：浅色 → 深色 → 跟随系统；auto 模式 30 秒轮询 Windows 注册表 `AppsUseLightTheme` 即时切换；兼容旧 `theme/dark` 键。
- **字号缩放**：`AppTheme.set_font_scale`（0.85~1.3）通知所有视图刷新；⚙️ 设置面板统一收纳透明度 + 字号滑块。
