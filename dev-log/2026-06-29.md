## Bug 修复记录

### Bug 1：没有退出按钮
- **根因**：最初的设计是关闭=最小化到托盘，但缺少明确的退出途径
- **修复**：在展开视图标题栏添加了 ✕ 退出按钮（红底 hover），连接到 `controller._on_quit()`
- **关联文件**：`app/views/expanded_view.py`, `app/controllers/app_controller.py`

### Bug 2：展开后黑条贯穿 UI
- **根因**：`setFixedSize()` 在折叠模式下锁死了窗口尺寸为 320×48。展开时先切换视图再动画，但视图在 48px 的限制下渲染，导致内容被压缩成一条黑线
- **修复方案**：展开/折叠前先调用 `setFixedSize(QSize(16777215, 16777215))` 解除固定尺寸。动画 **完成后** 再锁定为目标尺寸
- **关联文件**：`app/views/main_window.py`

### Bug 3：运行 main.py 出现 CMD 窗口
- **原因**：`python main.py` 默认带控制台
- **修复方案**：创建 `run_hidden.bat`，使用 `pythonw.exe` 启动（无控制台窗口）
- **使用方法**：双击 `run_hidden.bat` 启动；双击 `run.bat` 调试模式启动
- **日后打包**：PyInstaller 用 `--windowed` / `-w` 标志可生成无控制台的 EXE
