# 开发日志 — 2026-06-29

## 今日完成

### 窗口阴影美化 ✅
- **方案**：开启 `WA_TranslucentBackground` 使窗口透明，`QGraphicsDropShadowEffect` 直接加在主窗口上
- **布局调整**：主布局增加 15px 边距留出阴影投射空间
- **视图样式**：`CollapsedView` / `ExpandedView` 各自带 `border-radius: 8px` + 背景色，不再依赖外层容器
- **关键发现**：`QGraphicsDropShadowEffect` 在任何模块方法内调用都会被 Qt 清除，
  必须在 `main.py` 入口 `AppController()` 创建之后、`app.exec()` 之前从模块外部应用
- **关联文件**：
  - `main.py` — 从入口应用阴影
  - `app/views/main_window.py` — WA_TranslucentBackground、SHADOW_MARGIN、布局边距
  - `app/views/collapsed_view.py` — 恢复 border 和 border-radius 样式
  - `app/views/expanded_view.py` — 整体 border-radius + 底部圆角
  - `app/controllers/app_controller.py` — 暴露 `window()` 访问器
