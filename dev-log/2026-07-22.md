# 开发日志 2026-07-22

## 版本：v0.3.0 → v0.3.1

本次为代码质量与架构优化版本，不涉及功能新增。

## 已完成

### Phase 1：基础重构
- **AppTheme 通用按钮样式工厂**：新增 `icon_btn()`、`toggle_btn()`、`outline_btn()`、`danger_btn()`、`danger_fill_btn()`、`accent_fill_btn()`、`text_link_btn()`、`close_btn()`、`search_bar_style()`、`progress_input_style()`、`edit_input_style()` 共 11 个工厂方法
- **主题观察者机制**：`AppTheme.register(listener)` 自动通知，控制器不再手动遍历视图

### Phase 2：ExpandedView 拆分
- **TitleBar** 独立组件（166 行），管理标题栏所有按钮
- **DragDropManager** 独立模块（213 行），封装拖放排序全部逻辑
- ExpandedView 从 1,047 行降至 696 行（-34%）

### Phase 3：架构优化
- **搜索过滤**：控制器维护 `_search_query`，`_refresh_views()` 自动保持搜索状态
- **单实例锁**：`QSharedMemory` → `QLockFile`，崩溃后自动释放
- **弱引用**：`_progress_expanded_card` 改用 item_id 索引
- **事件优化**：`ClickableElidedLabel` 只拦截左键事件

### Phase 4：性能优化
- **差异化刷新**：`refresh()` 维护 `_card_map` 映射表，按需增删改单张卡片，避免全部销毁重建

### Phase 5：质量保障
- 新增 33 项 pytest 测试（数据模型 + 存储 CRUD），全部通过
