# 开发日志 2026-08-17

## 今日完成事项

### 代码审查优化（一次性清理）

**静态检查**
- `ruff check .` 由 82 个问题清理至 0：未使用导入、导入排序、
  `Optional[...]` → `X | None`、`IOError` → `OSError`、
  B904 `raise ... from e`、B905 `zip(strict=)`、UP031 百分号格式化、
  无意义 f-string 等。
- `main.py`：移除未使用的 `Qt` 导入；`AppController()` 改为 `_` 存活引用
  （避免失去 Python 引用导致 QObject 被 GC、应用退出，并消除 F841 告警）。

**性能优化**
- `ExpandedView._find_card()`：线性扫描 → 直接使用 `_card_map` 字典 O(1) 查找。
- `PetView.load_pet()`：可传入已扫描的素材列表，
  `AppController` 启动/切换形象时不再重复执行 `discover_pets()` 磁盘扫描。
- `ArchiveDialog` 搜索加入 300ms 防抖（与主搜索一致），
  避免每次按键全量重建归档列表。
- `ThemeService` 的系统主题 30s 轮询定时器仅在“跟随系统”模式下运行，
  切换出 auto 时停止。

**正确性 / 健壮性**
- 修复：标题内联编辑改变 #标签 后，若处于标签筛选，
  不再出现“已不满足筛选却仍显示在列表”的残留卡片
  （`_on_title_changed` 统一走差分刷新 `_refresh_views()`）。
- `ExpandedView.refresh()` 移除不再显示的卡片时先 `takeAt` 移出布局再
  `deleteLater`，避免残留/闪烁。
- `ReminderService` 只把“实际已提醒”的 id 写入当天提醒记录，
  避免未来到期项提前占位导致当天改期后漏提醒。
- `TitleBar.settings_btn_global_rect / more_btn_global_rect` 重命名为
  `settings_btn_rect / more_btn_rect`（实际为父窗口坐标系，原命名有误导）。

**清理**
- 删除 `PetView` 重复的“动画总开关”注释。
