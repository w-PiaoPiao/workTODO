## 🐛 Bug 修复：开机自启不生效

**问题：** 用户打开 ⚡ 开机自启后，重启电脑应用没有自动启动。

**根因：** `AppController._on_toggle_autostart()` 中脚本路径计算错误。

```python
script = Path(__file__).resolve().parent.parent / "main.py"
```

`__file__` 位于 `app/controllers/app_controller.py`：
- `.parent` → `app/controllers/`
- `.parent.parent` → `app/`  ❌（以为 main.py 在 `app/` 下面）

应改为 `.parent.parent.parent` 才能到达项目根目录。

注册表中写入的路径实际指向不存在的 `app/main.py`，开机时 Python 报"找不到文件"静默失败。

**修复：**
1. 将 `.parent.parent` 改为 `.parent.parent.parent`，正确指向项目根目录
2. 打包 EXE 模式下，`applicationFilePath()` 返回的 EXE 路径未加引号包裹，用户名含空格时也会失败。已加上引号
3. 新增日志记录，方便后续排查

**涉及文件：**
- `app/controllers/app_controller.py` — `_on_toggle_autostart()` 路径修正 + 引号包裹 + 日志

## 🐛 Bug 修复：双击任意位置导致窗口折叠

**问题：** 双击待办列表任意区域（进度文本、卡片空白区等）都会导致窗口折叠/收起。

**根因：** `MainWindow.mouseDoubleClickEvent` 无条件调用 `toggle_mode()`，而 `ElidedLabel`（进度文本组件）设置了 `WA_TransparentForMouseEvents` 导致鼠标事件穿透，双击事件冒泡到 `MainWindow`。

**修复方案** — 将双击折叠/展开的职责下放到具体视图层：

| 文件 | 改动 |
|---|---|
| `app/views/main_window.py` | 移除 `mouseDoubleClickEvent` 中的 `toggle_mode()` 调用，仅调 `super()` |
| `app/views/collapsed_view.py` | 新增 `mouseDoubleClickEvent`，双击折叠条任意位置发射 `signal_expand_clicked` |
| `app/views/expanded_view.py` | 标题栏 QWidget 安装事件过滤器，检测 `MouseButtonDblClick` → 发射 `signal_collapse_clicked` |

**额外保护：** `ExpandedView.eventFilter` 前加 `_built` 标志检查，防止 `_build_ui` 过程中事件先于属性初始化触发导致 `AttributeError`。标题栏的 `installEventFilter` 先赋值 `self._title_bar = bar` 再安装过滤器。

**涉及文件：**
- `app/views/main_window.py`
- `app/views/collapsed_view.py`
- `app/views/expanded_view.py`
