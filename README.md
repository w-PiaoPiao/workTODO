# 📋 待办事项和便签

> Windows 桌面悬浮待办事项软件 — 像便利贴一样悬浮在桌面，支持深色/浅色主题、进度追踪、卡片排序。

![Python](https://img.shields.io/badge/Python-3.12-blue) ![PySide6](https://img.shields.io/badge/PySide6-6.11%2B-green) ![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-lightgrey) ![Version](https://img.shields.io/badge/Version-0.2.0-orange)

---

## ✨ 功能亮点

| 功能 | 说明 |
|------|------|
| 🪟 **桌面悬浮** | 窗口始终置顶，不被其他窗口遮挡，随时可见 |
| ↔️ **折叠/展开** | 折叠为紧凑条（仅显示计数），展开为完整待办列表 |
| 🌗 **深色/浅色主题** | 一键切换，跟随系统偏好，持久化记忆 |
| ⚡ **快速添加** | 折叠/展开模式下都能一键添加新待办 |
| 📝 **进度追踪** | 每条待办可多次添加进度描述，自动记录时间戳 |
| ✅ **一键办结** | 勾选完成，自动归档，历史可查 |
| 📦 **归档管理** | 办结内容移入归档，支持搜索查看和恢复 |
| 🔍 **搜索筛选** | 按关键词实时过滤待办和进度内容（300ms 防抖） |
| 🗂️ **卡片拖拽排序** | 拖拽卡片自由排序，拖拽时有半透明预览和插入指示线 |
| 🔖 **窗口置顶** | 窗口置顶/取消一键切换，记忆首选项 |
| 🖱️ **进度折叠** | 只显示最新一条进度，点击 ▼ 展开全部 |
| 🏷️ **卡片置顶** | 重要待办置顶到列表最前，带飞入动画 |
| ✏️ **内联编辑** | 双击标题直接编辑，支持 Escape 取消 |
| ⏻ **开机自启** | 一键设置开机自动启动（Windows） |
| 🎯 **系统托盘** | 最小化到托盘后台运行，不占用任务栏 |
| ⌨️ **键盘快捷键** | Ctrl+N 新建、Ctrl+F 搜索、Esc 折叠 |
| 🖥️ **多显示器** | 自动吸附当前所在屏幕边界 |
| 🔒 **单实例** | 防止同时打开多个窗口 |

## 🚀 快速开始

### 环境要求

- Windows 10 或 Windows 11
- Python 3.12+

### 安装与运行

```bash
# 1. 克隆项目
git clone <仓库地址>
cd 待办事项和便签

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python main.py

# 调试模式（输出详细日志）
python main.py --debug
```

### 打包为独立 EXE

```bash
pip install pyinstaller>=6.21

pyinstaller --onefile --windowed \
    --name "待办事项和便签v0.2.0" \
    --clean --noconfirm \
    main.py
```

产物位于 `dist/待办事项和便签v0.2.0.exe`（约 46 MB，含 PySide6 完整运行时）。

## 📖 使用指南

### 基本操作

| 操作 | 方式 |
|------|------|
| **新建待办** | 展开模式下输入框回车，或折叠模式下 [＋] |
| **快捷新建** | `Ctrl+N` |
| **搜索** | `Ctrl+F` |
| **办结** | 卡片上的 [办结] 按钮 |
| **删除** | 卡片上的 [✕] 按钮（弹出确认） |
| **编辑标题** | 双击标题文字，`Escape` 取消 |
| **添加进度** | 卡片底部输入进度后回车 |
| **展开全部进度** | 点击进度前的 ▼ |
| **卡片排序** | 拖拽卡片到目标位置 |
| **置顶卡片** | 点击卡片上的 [↑] |
| **切换主题** | 标题栏 [🌙/☀️] 按钮 |
| **设置开机自启** | 标题栏 [⚡] 按钮 |
| **窗口置顶** | 标题栏 [📌] 按钮 |
| **折叠/展开** | 双击标题栏空白，或 [━] 按钮 |
| **查看归档** | 页脚 [📦 查看归档] |
| **最小化到托盘** | 点击关闭按钮 |
| **退出应用** | 页脚 [✕ 退出] 或托盘右键菜单 |

### 数据存储

数据文件默认存储在用户数据目录（由 `appdirs` 决定），或通过环境变量 `FLOATING_TODO_DATA_DIR` 自定义路径。

| 文件 | 内容 |
|------|------|
| `todos.json` | 活跃待办事项 |
| `archive.json` | 已归档的待办事项 |

## 🏗 软件架构

采用 **MVC 模式**，通过 Qt 信号/槽机制解耦：

```
┌──────────┐   信号   ┌──────────────┐  CRUD  ┌──────────┐
│ PySide6  │ ──────→  │ AppController │ ─────→ │ TodoStore │
│  Views   │ ←──────  │ (Controller)  │ ←───── │ (Model)   │
└──────────┘  信号     └──────────────┘        └────┬─────┘
                                                     │
                                              ┌──────┴──────┐
                                              │  JSON 文件    │
                                              │  (持久化)     │
                                              └─────────────┘
```

### 数据安全

所有 JSON 文件采用**原子写入**策略，防止写入中断导致文件损坏：

1. 先写入 `.tmp` 临时文件
2. 通过 `Path.replace()` 原子替换原文件（NTFS 特性）
3. 若检测到 JSON 损坏，自动备份为 `.bak` 并重建
