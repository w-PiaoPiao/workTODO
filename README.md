# 📋 待办事项和便签

> Windows 桌面悬浮待办事项软件 — 像便利贴一样悬浮在桌面，支持深色/浅色主题、进度追踪、卡片排序、截止日期提醒、彩色便签。

### 🐾 桌宠自定义形象

把图片文件放入以下任一目录，即可在 **设置面板（⚙️）→ 宠物** 中切换：

- `%LOCALAPPDATA%\待办事项和便签\pets\`（推荐，打包后也可随时添加）
- `app/resources/pets/`（内置目录，随源码/打包分发）

支持 PNG / JPG / GIF，文件名即形象名。**白底 JPG/PNG 会自动去除背景**（仅清除连通到边缘的白色，角色内部白色保留），处理结果缓存于 `pets/_processed/`，修改原图后自动重新处理。

建议素材规格：正方形、512×512 以上、主体居中。桌宠右键菜单可随时**暂停/恢复空闲动画**（记忆首选项）。

## 🚀 快速开始

### 环境要求

- Windows 10 或 Windows 11
- Python 3.12+

### 安装与运行

```bash
# 1. 克隆项目
git clone <仓库地址>
cd 待办事项和便签

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python main.py

# 调试模式（输出详细日志）
python main.py --debug
```

### 打包为独立 EXE

```bash
pip install pyinstaller>=6.21

pyinstaller --onefile --windowed \
    --name "待办事项和便签v0.4.0" \
    --icon "app/resources/icon.ico" \
    --add-data "app/resources;app/resources" \
    --clean --noconfirm \
    main.py

产物位于 `dist/待办事项和便签v0.4.0.exe`（约 46 MB，含 PySide6 完整运行时）。

## 📖 使用指南

### 基本操作

| 操作 | 方式 |
|------|------|
| **新建待办** | 展开模式下输入框回车，或折叠模式下 [＋] |
| **快捷新建** | `Ctrl+N` |
| **搜索** | `Ctrl+F` |
| **办结** | 卡片上的 [办结] 按钮 |
| **删除** | 卡片上的 [✕] 按钮（弹出确认） |
| **编辑标题** | 双击标题文字，`Escape` 取消 |
| **设置截止日期** | 卡片上的 [📅] 按钮，输入 `YYYY-MM-DD`，留空清除 |
| **分类标签** | 标题输入 `#标签` 自动识别，点标题栏上方标签筛选 |
| **添加进度** | 卡片底部输入进度后回车 |
| **编辑进度** | 展开全部进度，双击进度文本（hover 蓝色边框提示） |
| **删除进度** | 展开全部进度，点击进度行末尾 ✕ 按钮 |
| **展开全部进度** | 点击进度前的 ▼ |
| **卡片排序** | 拖拽卡片到目标位置 |
| **置顶卡片** | 点击卡片上的 [↑] |
| **切换主题** | 标题栏 [🌙/☀️/🌗] 按钮（浅色→深色→跟随系统） |
| **设置开机自启** | 标题栏 [⚡] 按钮 |
| **窗口透明度/字号** | 标题栏 [⚙️] 按钮，拖动滑块调整 |
| **查看统计** | 标题栏 [📊] 按钮 |
| **窗口置顶** | 标题栏 [📌] 按钮 |
| **切换待办/便签** | 标题栏下方 [📋 待办] / [📝 便签] 标签 |
| **新建便签** | 便签页右上角 [＋ 新建便签]，双击卡片编辑 |
| **导出/导入备份** | 页脚 [💾 备份] 按钮 |
| **折叠/展开** | 双击标题栏空白，或 [━] 按钮 |
| **查看归档** | 页脚 [📦 查看归档] |
| **最小化到托盘** | 点击关闭按钮 |
| **退出应用** | 页脚 [✕ 退出] 或托盘右键菜单 |

### 数据存储

数据文件默认存储在用户数据目录（由 `appdirs` 决定），或通过环境变量 `FLOATING_TODO_DATA_DIR` 自定义路径。

| 文件 | 内容 |
|------|------|
| `todos.json` | 活跃待办事项 |
| `archive.json` | 已归档的待办事项 |
| `notes.json` | 便签笔记 |

## 🏗 软件架构

采用 **MVC 模式**，通过 Qt 信号/槽机制解耦：

```
┌──────────┐   信号   ┌──────────────┐  CRUD  ┌──────────┐
│ PySide6  │ ──────→  │ AppController │ ─────→ │ TodoStore │
│  Views   │ ←──────  │ (Controller)  │ ←───── │ (Model)   │
└──────────┘  信号     └──────────────┘        └────┬─────┘
                                                     │
                                              ┌──────┴──────┐
                                              │  JSON 文件    │
                                              │  (持久化)     │
                                              └─────────────┘
```

### 数据安全

所有 JSON 文件采用**原子写入**策略，防止写入中断导致文件损坏：

1. 先写入 `.tmp` 临时文件
2. 通过 `Path.replace()` 原子替换原文件（NTFS 特性）
3. 若检测到 JSON 损坏，自动备份为 `.bak` 并重建

## 👨‍💻 开发
